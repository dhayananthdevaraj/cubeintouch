TITLE: Retrieve Shipment Details by ID
DIFFICULTY: Medium
LANGUAGE: Java_jdbc
TAGS: java, jdbc, mysql

DESCRIPTION:
<p><strong><u>Problem Statement</u></strong></p>
<p><br></p>
<p>Priya, a logistics manager at a warehouse company, manages shipment tracking using a MySQL database. Her database table shipment contains the following records:</p>
<p>(1, 'Laptops', 50, 'Delivered')</p>
<p>(2, 'Mobile Phones', 100, 'In Transit')</p>
<p>(3, 'Office Chairs', 20, 'Pending')</p>
<p>(4, 'Desks', 30, 'Delivered')</p>
<p>(5, 'Monitors', 60, 'In Transit')</p>
<p><br></p>
<p>Priya needs a Java program that takes a shipmentId as input and retrieves the corresponding shipment details — including ID, Item Name, Quantity, and Status — from the shipment table. If no shipment with the given shipmentId exists, the program should output a message stating that no such shipment is found.</p>
<p><br></p>
<p>Help her fetch the shipment information accurately.</p>
<p><br></p>
<p>The system should connect to a MYSQL database using the following default credentials:</p>
<ol><li>DB URL: jdbc:mysql://localhost/ri_db</li><li>Username: test</li><li>Password: test123</li></ol>

INPUT_FORMAT:
<p>The input consists of an integer representing the shipmentId for which the details need to be retrieved.</p>

OUTPUT_FORMAT:
<p>If the shipment is found, the output should be:</p>
<p>Shipment Details:</p>
<p>ID: &lt;shipmentId&gt;</p>
<p>Item Name: &lt;itemName&gt;</p>
<p>Quantity: &lt;quantity&gt;</p>
<p>Status: &lt;status&gt;</p>
<p><br></p>
<p>If the shipment is not found, the output should be:</p>
<p>No shipment found with ID &lt;shipmentId&gt;</p>
<p><br></p>
<p><strong>Refer to the sample output for formatting specifications.</strong></p>

CONSTRAINTS:
The given testcases fall under the following constraints:
1 ≤ shipmentId ≤ 5 for an existing record; any other positive integer is treated as "not found"

SOLUTION[Java_jdbc]:
try {
            // Step 1: Establish the connection
            conn = DriverManager.getConnection(url, username, password);

            // Step 2: SQL query to retrieve shipment details by ID
            String query = "SELECT id, item_name, quantity, status FROM shipment WHERE id = ?";

            // Step 3: Create a PreparedStatement to execute the query
            pstmt = conn.prepareStatement(query);
            pstmt.setInt(1, shipmentId);

            // Step 4: Execute the query and get the ResultSet
            rs = pstmt.executeQuery();

            // Step 5: Process the result set and display shipment details
            if (rs.next()) {
                int id = rs.getInt("id");
                String itemName = rs.getString("item_name");
                int quantity = rs.getInt("quantity");
                String status = rs.getString("status");

                System.out.println("Shipment Details:");
                System.out.println("ID: " + id);
                System.out.println("Item Name: " + itemName);
                System.out.println("Quantity: " + quantity);
                System.out.println("Status: " + status);
            } else {
                System.out.println("No shipment found with ID " + shipmentId);
            }
        }
